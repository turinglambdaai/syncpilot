SyncPilot

The official Resilio Sync experience, on Linux.

v0.2.0 · deb · rpm · AppImage · x86_64 + aarch64

Resilio Sync ships official desktop clients for Windows and macOS — on Linux you only get a Web UI. SyncPilot puts the official Resilio Web UI inside a native desktop window and manages the official rslsync daemon behind it: every screen, control and workflow is the official one — folders, peers, transfers, preferences, activation — with the desktop integration Linux was missing on top.

Highlights

  • Official interface, zero drift — nothing to re-learn, version-matched to your rslsync build; activation and identity setup run through the official wizard
  • Daemon lifecycle — one-click start/stop, adopts an already-running daemon, crash watchdog with exponential backoff
  • First-run setup — offers to download the official rslsync binary from Resilio's CDN (sha256-verified) if none is found
  • In-app updates — signed updater artifacts checked against the GitHub release
  • Desktop integration — tray icon, hide-to-tray, launch at login, standalone settings window
  • Safe by construction — the Web UI stays on 127.0.0.1 behind an auth-injecting loopback proxy; the daemon never serves an unauthenticated request

Get it

Install the package, launch SyncPilot, done — if the official rslsync binary is not installed yet, the app offers to fetch it on first start.
