SyncPilot

The Resilio Sync desktop client Linux deserves.

Resilio Sync ships official GUI clients for Windows and macOS — on Linux you only get a Web UI. SyncPilot wraps the official rslsync binary in a native desktop app: folders, peers, transfers, pause/resume, speed limits and a tray icon, talking to the daemon over loopback only.

Screenshot placeholder — overview page with transfer-rate graph and folder grid.

Highlights

  • One-click daemon lifecycle with crash watchdog and already-running adoption
  • Add folders by share key or create new ones with read & write / read-only keys
  • Peer connection state, sync progress and per-peer speeds
  • Global pause/resume, up/down speed limits, live rate graph
  • Tray icon, hide-to-tray, launch at login
  • Web UI forced to 127.0.0.1 with app-generated credentials

Get it

deb / rpm / AppImage for x86_64 and aarch64 from GitHub Releases. Requires the official rslsync binary on the system.
